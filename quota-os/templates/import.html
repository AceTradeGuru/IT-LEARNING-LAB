Import from Salesforce or HubSpot

Export your opportunities or deals as CSV and drop the file here. QuotaOS reads the header row, works out which system it came from, maps the stages onto ours, and shows you exactly what it would create, update, and skip — before anything is written.

Upload an export

Up to 4 MB — roughly 30,000 opportunities. CSV only; export from Excel as CSV if your download is .xlsx.

How to get the file

Salesforce
Reports → New Report → Opportunities → run it → Export → Details Only, CSV. Include at minimum Opportunity ID, Account Name, Amount, Stage, Close Date, and Opportunity Owner.

HubSpot
Sales → Deals → the ⋯ menu → Export → CSV. Include Record ID, Deal Name, Amount, Deal Stage, Close Date, and Deal owner.

Why importing twice is a feature

No CRM export contains the date a deal was originally forecast to close — only where it stands today. So the first import records the current close date as the original, and nothing looks slipped. From the second import onward, QuotaOS keeps that original while the current date moves, which is how a deal that has been pushed three times becomes visible here and never was in the system it came from. Deals are matched on their Salesforce or HubSpot record id, so re-importing the same export updates rather than duplicates.
